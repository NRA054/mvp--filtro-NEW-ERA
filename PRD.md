Punto de Entrada: El usuario accede al sitio web o app de New Era y encuentra el banner: "¿No sabes cuál elegir? Encuentra tu estilo perfecto con nuestro Asesor IA".

Perfilado Inicial (Input de datos):

El sistema solicita permiso para usar la cámara (para análisis de rostro) o permite al usuario seleccionar manualmente su tipo de rostro (ovalado, cuadrado, etc.).


Un breve quiz de 2 preguntas sobre gustos: (ej. ¿Uso diario o deportivo? ¿Prefieres estilo sobrio o llamativo?).


Procesamiento: El motor de recomendación cruza los datos fisionómicos y de estilo con el inventario disponible en tiempo real.


Visualización (AR): Se despliega una lista de 3 opciones recomendadas. El usuario puede activar el Probador Virtual para ver cómo le queda el modelo seleccionado.


Ya para finalizar y haberse probado las 3 opciones sugeridas por el filtro, el usuario pueda escoger alguna de las 3 opciones y obtener variaciones de color, dependiendo asi para que ocasion decida usar su gorra.
