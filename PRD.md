# PRD

## Visión del producto

Crear un asistente de selección de gorras New Era que combina la forma de rostro del usuario con sus preferencias de estilo para generar recomendaciones útiles y visuales.

## Flujo de usuario

1. El usuario accede al sitio y ve una invitación clara: "¿No sabes qué gorra elegir? Prueba nuestro asesor visual".
2. Se pide permiso para usar la cámara o el usuario elige su tipo de rostro manualmente.
3. El usuario responde un mini-quiz de preferencias: uso, estilo y colores.
4. El sistema genera hasta 3 recomendaciones ajustadas al tipo de rostro y a la curaduría de estilo.
5. El usuario puede previsualizar el resultado con un probador virtual AR o revisar variaciones de color.
6. Finalmente, elige una gorra recomendada y recibe opciones de complementos o estilos relacionados.

## Requisitos clave

- Análisis de rostro ligero y fácil de usar.
- Interfaz simple y clara para el quiz.
- Recomendaciones enfocadas en siluetas de gorras New Era.
- Prueba virtual que muestre al usuario el modelo sobre su rostro.

## Criterios de éxito

- Usuario entiende la propuesta en menos de 10 segundos.
- Recomendaciones relevantes para la forma de rostro y el estilo visual.
- La experiencia se percibe como útil y confiable.

## Prioridades del MVP

- Garantizar la guía visual de selección.
- Simplificar la interacción para reducir fricción.
- Mantener el desarrollo enfocado en el frontend y en la experiencia de usuario.
