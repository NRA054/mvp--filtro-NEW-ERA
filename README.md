# mvp--filtro-NEW-ERA

`mvp--filtro-NEW-ERA` es una experiencia digital para ayudar a elegir la gorra New Era ideal según la forma del rostro y el estilo personal.

## ¿Qué resuelve?

- Dificultad para identificar qué silueta de gorra favorece más al usuario.
- Incertidumbre en compras online que genera devoluciones o insatisfacción.
- Falta de guía visual que muestre cómo quedaría la gorra antes de comprar.

## Solución propuesta

- Análisis fisionómico ligero para clasificar el tipo de rostro: ovalado, redondo, cuadrado o corazón.
- Quiz de preferencias rápido para entender el uso y estilo: deportivo, urbano, minimalista, colores y ocasión.
- Recomendaciones personalizadas que cruzan forma de cara y estilo para proponer siluetas de gorras.
- Prueba virtual AR simple para visualizar modelos sobre la cara.

## Valor del producto

- Mejora la experiencia de compra con recomendaciones con sentido.
- Reduce la fricción y aumenta la confianza del cliente.
- Posiciona a New Era como una marca que acompaña en la decisión de estilo.

## Enfoque del MVP

- Priorizar la experiencia del usuario en el frontend.
- Aprovechar visión artificial y AR directamente en el navegador cuando sea posible.
- Mantener el proyecto ligero y fácil de iterar.
